# ミナセイメージング調査

架空の複合機メーカーサイトを巡回し、旧型複合機「MI-4040」に関する不自然な情報から調査コードを導く短編Web ARGです。

## 遊び方

1. `index.html` を開きます。
2. 入口の注意書きを確認し、企業HP風ページへ進みます。
3. お知らせ、製品、FAQ、更新履歴、導入事例、会社情報を読み、調査コードを組み立てます。
4. `terminal/index.html` の照合端末にコードを入力します。

正解コードは `MI4040-21704-ARCHIVE` です。

## 公開方法

GitHub Pages で静的サイトとして公開できます。サーバー処理、外部ライブラリ、外部APIは使用していません。

1. リポジトリにこのファイル一式を配置します。
2. GitHub のリポジトリ設定で Pages を開きます。
3. Source を `Deploy from a branch` にします。
4. Branch に公開するブランチを選び、公開フォルダを `/root` にします。
5. 保存後、表示された Pages URL にアクセスします。

すべて相対パスで実装しているため、リポジトリ名付きのサブディレクトリURLでも動作します。

## 検索避け設定

全HTMLに `<meta name="robots" content="noindex, nofollow">` を入れています。ルートには `robots.txt` を置き、全クローラーに対して `Disallow: /` を指定しています。`sitemap.xml` は作成していません。

これは検索結果に出にくくするための設定ですが、URLを知っている人のアクセスを制限するものではありません。
